# Word partners

A one-page tool for pairing up confusable words, so they can be practised
together in [Clepsydra](https://karstenlrvun.github.io/clepsydra/).

Open it at **https://karstenlrvun.github.io/clepsydra-pairs/**

Each flagged word is shown on its own card with the words it is most likely
confused with. Number keys pair and move on (`1`–`4`), shift picks several,
`space` is "not sure", `n` is "no partner", `s` searches the deck, `c` writes
the note the drill shows on a miss, and backspace undoes. The list view is on
`L`. Ticks are kept in the browser; **Download the file** writes the file
Clepsydra reads under Settings → Backups → Bring in tied pairs, and **Load a
file** reads one back, so progress can move between devices.

The page holds the two word lists and which of them are flagged. It is a
scratch tool: delete the repository when the sorting is done.

Generated by `tools/make-pairs-list.js` in the Clepsydra development repo.
